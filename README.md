# RASP

RASP is an experimental, vibe-coded project.

The aim is to build a portable Classic ASP interpreter in Rust. The long-term goal is to produce a single Rust binary and a Docker image that can run existing Classic ASP applications on any platform that supports containers.

The project plan and current implementation status are kept in:
